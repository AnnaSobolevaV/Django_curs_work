# Django_curs_work
Сервис почтовых рассылок.
Сервис управления рассылками - приложение, которое позволяет пользователям управлять рассылками сообщений для клиентов.
Приложение включает функциональность для создания, просмотра, редактирования и удаления рассылок, сообщений, 
получателей сообщений, а также отправки рассылок по необходимости. Собирается и выводится статистика попыток отправки сообщений согласно ТЗ.
Реализованна система регистрации и аутентификации пользователей сервиса. Ограничены права доступа. Реализовано серверное кэширование.

Для запуска сервиса необходимо заполнить файл .env (см. Django_curs_work/.env.exmpl).
установить все необходимые пакеты, согласно Django_curs_work/pyproject.toml.
После установки Redis запустите сервер, выполнив команду: redis-server
